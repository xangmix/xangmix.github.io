AWR 흐름 지도

형광펜 비유. 학생들의 풀이 노트(데이터)를 쌓아 놓고, 평균보다 잘 푼 풀이일수록 형광펜을 진하게 칠한 다음, 진하게 칠한 곳 위주로 따라 쓰기 연습을 해요. 이 따라 쓰기가 BC(Behavior Cloning, 행동 복제)예요. 형광펜 굵기가 ω = exp(A/β)예요.

AWR = 회귀 두 번. ① V를 실제 점수 R에 맞추고(MSE) ② 데이터 행동을 ω만큼 따라 해요(가중치 BC).

V ← argmin E[(R − V(s))²] → π ← argmax E[ log π(a|s) · exp((R − V(s))/β) ]

데이터·환경 V (점수 매기는 쪽) 정책 π = SmolVLA(θ) θ가 바뀌는 곳

3. 식이 어떻게 이어지나 (논문 식 번호 그대로)

위에서 아래로 한 줄씩 내려가면 알고리즘이 나와요. 내일 논문 읽을 때 이 순서대로 따라가면 돼요.

  1. 식 2

    출발점: RWR (조상)

    π_{k+1} = argmax E[ log π(a|s) · exp(R / β) ]

    점수 R 자체를 형광펜으로 써요. 모든 판 점수가 양수면 못한 판도 꽤 진하게 칠해져요. baseline이 없어서 그래요.

  2. 식 3

    목표: 데이터 정책보다 얼마나 나아지나

    η(π) = J(π) − J(μ) = E_{s∼d_π, a∼π}[ A^μ(s, a) ]

    μ = 데이터를 만든 정책이에요. "점수 최대화" 대신 "μ 대비 개선"을 목표로 잡으면 A(= R − V)가 자연스럽게 들어와요.

  3. 식 4

    근사: 새 정책이 갈 상태는 모르니 데이터 상태로 잰다

    η̂(π) = E_{s∼d_μ, a∼π}[ R^μ(s, a) − V^μ(s) ]

    d_π(새 정책이 방문할 상태)는 직접 돌려 봐야 알 수 있어요. 그래서 데이터에 있는 상태 d_μ로 바꿔요. π가 μ와 가까울 때만 맞는 근사예요.

  4. 식 5·6

    목줄: 데이터에서 너무 멀어지지 마

    max η̂(π) s.t. E_{s∼d_μ}[ KL( π(·|s) ‖ μ(·|s) ) ] ≤ ε

    KL = 두 분포가 얼마나 다른지 재는 거리예요. PPO의 clip(0.8~1.2)과 같은 역할(trust region)이라 Part2에서 PPO로 넘어가는 다리가 돼요.

  5. 식 7·8

    정답: 데이터 분포에 형광펜을 곱해 다시 줄 세우기

    π*(a|s) = μ(a|s) · exp( A(s, a) / β ) / Z(s)

    라그랑주 승수법으로 풀면 이 꼴이 나와요. β가 라그랑주 승수 = 목줄 길이예요. Z는 합을 1로 맞추는 값이에요. 2번 슬라이더가 바로 이 식이에요.

  6. 식 9·10

    신경망으로 옮기면 = 가중치 BC

    argmin E[ KL(π* ‖ π) ] = argmax E_{(s,a)∼D}[ log π(a|s) · exp(A / β) ]

    π*를 신경망에 그대로 넣을 수는 없어요. 그래서 가장 가까운 π를 찾는데, 풀어 보면 "데이터 행동의 log 확률 × ω"만 남아요. 이게 알고리즘 6번 줄(④)이에요.

  7. 식 15·16

    여러 정책 데이터가 섞여도 V 하나면 된다

    V̄ = argmin_V E_D[ (R − V(s))² ] → 섞인 정책들 V의 가중 평균

    버퍼에는 과거 정책 π₁…π_k의 판이 섞여 있어요. V를 정책마다 따로 두지 않고 하나만 MSE로 맞춰요. MSE 최솟값 = 평균이라서, 필요한 가중 평균 baseline이 자동으로 나와요. 알고리즘 5번 줄(①)이에요.

  8. 3.3절

    실전 손질

    R: MC → TD(λ = 0.95) · β = 0.05 고정 · ω ≤ 20 · 상태는 버퍼에서 균일 샘플

    MC는 분산이 커서 TD(λ)로 바꿨어요(MC도 되지만 조금 나빴어요). β는 따로 조절하지 않고 고정해도 됐어요. ω가 폭발하면 gradient도 폭발해서 20에서 잘라요.
